🌍 GeoVista – Project Description
✨ Overview

GeoVista is a secure web-based map visualization platform that generates beautiful customizable maps using OpenStreetMap data.

🚀 Key Features
🔐 Login & Registration
Secure user authentication
Protected access to platform

📍 Location Search
Search any address/place worldwide
Automatic geocoding of locations

🗺️ Map Generation
Creates aesthetic maps instantly
Uses live OpenStreetMap geographic data

🎨 Custom Styling
Multiple map themes
Editable colors and layouts
Circle / Square / Rectangle map shapes

📤 Export Options
Download as PNG / SVG
Export GeoJSON data
Save map configuration

🌟 Benefits
⚡ Fast & User Friendly
No GIS knowledge required
Simple interactive interface

🔄 Real-Time Data
Uses updated OpenStreetMap data

🛡️ Secure Platform
Authentication protects user access

📈 Professional Output
High-quality maps for reports/presentations

🛠️ Technologies Used
Streamlit – Web Interface
Prettymapp – Map Rendering
OpenStreetMap – Geographic Data
Geopy – Location Search
GeoPandas – Spatial Processing

🎯 Conclusion
GeoVista combines authentication, real-time map data, and customizable map generation into one modern geographic visualization platform.
